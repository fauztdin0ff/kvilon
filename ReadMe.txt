# Project Setup (Gulp)

## 📁 Структура проекта

- `dist/` — готовая собранная верстка для загрузки на сервер
- `src/` — исходники проекта (HTML, SCSS, JS, изображения, шрифты и т.д.)
- `gulpfile.js` — конфигурация Gulp
- `package.json` — список зависимостей и команд

---

## 🚀 Если необходимо редактировать проект

### 1. Установка проекта

Установите зависимости:

```bash
npm i
```

---

### 2. Запуск в режиме разработки

```bash
npm run dev
```

Работа ведётся в папке `src/`.

---

### 3. Финальная сборка проекта

```bash
npm run build
```

После сборки будет пересоздана папка `dist` с готовым production-проектом.
